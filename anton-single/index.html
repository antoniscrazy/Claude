              Hi, ich bin Anton, und ich bin Vibecoder.
              Das heißt: Ich habe die Ideen, und die KI (Claude) schreibt den Code. Den ganzen. Jede Zeile.
              Auch die Semikolons.
            

            

              Klassischer Entwickler? Nö. Ich habe nie gelernt, einen Bubble-Sort von Hand zu schreiben, und ich habe
              auch nicht vor, damit anzufangen. Dafür kann ich sehr ausdauernd beschreiben, was ich will, bis es da ist.
            

            

              Mein Job ist der spannende Teil: mir ausdenken, was es noch nicht gibt, entscheiden, wie es sich
              anfühlen soll, und so lange nachhaken, bis es passt. Die KI übernimmt den Teil mit den geschweiften Klammern.
            

            

              Manche nennen das Schummeln. Ich nenne es Delegieren. Und ganz ehrlich: Auch diese Website hat die KI geschrieben.
              Ich habe nur gesagt, wie sie aussehen soll. Und dass da ein Easter Egg rein muss.

supabase/raeume.sql


-- Geschrieben von: der KI. Abgenickt von: Anton.
create table buchungen (
  id uuid primary key default gen_random_uuid(),
  raum_id uuid references raeume(id),
  von timestamptz not null,
  bis timestamptz not null
);

select name from raeume
where id not in (
  select raum_id from buchungen
  where now() between von and bis
);
