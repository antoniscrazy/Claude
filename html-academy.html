        01

        Grundlagen

        Jede Website beginnt mit denselben sechs Bausteinen. Wer sie versteht, versteht das Web.

        I

        Tags

        Tags geben Inhalten Bedeutung. Fast jeder Tag hat einen Anfang und ein Ende.

        <p>Hallo Welt</p>
        II

        Attribute

        Attribute ergänzen Tags um Details – immer im Start-Tag, als name="wert".

        <p class="intro" id="start">
        III

        Links

        Links verbinden Dokumente. href nennt das Ziel, der Inhalt wird klickbar.

        <a href="/kurs">Weiter</a>
        IV

        Bilder

        Bilder brauchen eine Quelle und einen Alternativtext für alle, die sie nicht sehen.

        <img src="foto.jpg" alt="Ein Atelier">
        V

        Listen

        ul für Aufzählungen, ol für Reihenfolgen. Jeder Eintrag ist ein li.

        <ul><li>HTML</li></ul>
        VI

        Formulare

        Formulare sammeln Eingaben – mit label, input und button.

        <input type="email" required>

        Anatomie eines Tags

        Fahre über die Teile – oder tippe sie an. So ist jedes HTML-Element aufgebaut.

        Jedes Element besteht aus wenigen, klaren Bausteinen: Start-Tag, Attributen, Inhalt und End-Tag.

        Häufige Fragen

        Kurz und ehrlich beantwortet.

        Brauche ich Vorkenntnisse?

        Nein. Du brauchst nur Neugier, einen Browser und einen Texteditor. Alles Weitere lernst du hier Schritt für Schritt.

        Ist HTML eine Programmiersprache?

        Streng genommen nicht – HTML ist eine Auszeichnungssprache. Sie beschreibt, was Inhalte bedeuten. Für Aussehen sorgt CSS, für Logik JavaScript.

        Wie lange dauert der Kurs?

        Der Lernpfad umfasst etwa zweieinhalb Stunden. Du kannst jederzeit pausieren – es gibt keine Fristen.

        Wer hat diese Seite gebaut?

        Sechs Agents: Atlas plante das Layout, Lyra schrieb die Texte, Iris gestaltete, Nova verdrahtete die Logik, Pixel animierte und Echo prüfte die Barrierefreiheit.

        Wird hier etwas gespeichert oder gesendet?

        Nein. Keine Cookies, kein Tracking, keine Anfragen. Die Seite funktioniert komplett offline in deinem Browser.

        Bereit für deinen ersten Tag?

        Trag dich ein und erhalte die erste Lektion. (Demo – es wird nichts versendet, alles bleibt in deinem Browser.)
