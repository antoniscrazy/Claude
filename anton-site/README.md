# anton-site

Onepager für Anton, den Vibecoder. Reines HTML, CSS und Vanilla JS, ohne Build-Schritt.

## Lokal ansehen
`index.html` im Browser öffnen. Fertig.

## Deploy auf Netlify
Diesen Ordner (`anton-site`) auf https://app.netlify.com/drop ziehen.

## Offene Platzhalter (suche nach `TODO`)
- `index.html`: Moki-URL (`href="#"`)
- `index.html`: Flexspacepro-URL (`href="#"`)
- `index.html`: `og:image` / `og:url` auf die absolute Domain umstellen
- `index.html`: optional Discord-Username in der Profilkarte
- `index.html` (Footer): Impressum/Datenschutz, falls nötig
- `js/main.js`: `LANYARD_ENABLED = true` für den Live-Discord-Status (vorher dem Lanyard-Server beitreten)
