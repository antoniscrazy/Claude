# Sicherung der 2D-Einleitung

`megaintro-2d.js` ist die fertige 2D-Einleitung (Canvas, kein WebGL), Stand vor der 3D-Version.
Zurueckholen: Datei nach `moki/megaintro.js` kopieren und `python3 build.py` ausfuehren.
Die 3D-Version (intro3d/) faellt ausserdem selbst auf diese 2D-Einleitung zurueck, wenn WebGL fehlt oder etwas schiefgeht.
